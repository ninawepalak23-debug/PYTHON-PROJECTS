🍔 School Canteen Management System

A Python-based console application designed to manage basic school canteen operations, including food management, customer orders, billing, and feedback collection.

📌 Project Overview

The School Canteen Management System is a menu-driven application developed using Python. It helps manage food items, calculate customer bills, apply discounts, and collect customer feedback.

✨ Features

Display available food items and prices

Search for food items

Add new food items dynamically

Place customer orders

Generate bills automatically

Apply a 10% discount on orders of Rs. 200 or more

Collect customer feedback and ratings

Display feedback summaries and average ratings

Built-in help and project information

🛠️ Technologies Used

Python 3

Lists

Dictionaries

Loops and conditional statements

Functions of basic input/output

▶️ How to Run

Install Python 3.

Download or clone this repository.

Open a terminal in the project folder.

Run:

bash

python canteen.py
